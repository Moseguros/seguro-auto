## Especificação

Todos os value objects são `record` imutáveis, validam no construtor compacto e lançam `DomainException` com `code` indicado, status 400.

**Money** — `record Money(long amount, String currency)`: `amount` em centavos; `currency` sempre `"MZN"` (outro → `INVALID_CURRENCY`). Fábricas `Money.ofCentavos(long)`, `Money.ofMeticais(BigDecimal)` (arredonda HALF_UP a 2 casas; mais de 2 casas → arredonda), `Money.zero()`. Operações `plus`, `minus`, `times(BigDecimal)` (HALF_UP), `isNegative`, `compareTo`. JSON: `{"amount": 299900, "currency": "MZN"}`.

**Msisdn** — telemóvel moçambicano. Aceita `+258841234567`, `258841234567`, `841234567`, com espaços ou hífens. Normaliza para `258` + 9 dígitos. O número nacional tem 9 dígitos, começa por `8` e o segundo dígito está entre `2` e `7` (82–87). Senão `INVALID_MSISDN`. Métodos `e164()` → `+258841234567`, `national()` → `841234567`, `masked()` → `+258 84*****67`. JSON: string E.164.

**Nuit** — exactamente 9 dígitos após remover espaços; senão `INVALID_NUIT`. Sem dígito de controlo nesta fase (ver Questões). `masked()` → `*****6789`.

**Matricula** — normaliza: maiúsculas, remove espaços e hífens, e volta a formatar. Formatos aceites:
- actual: 3 letras + 3 dígitos + 2 letras → `ABC-123-MC`;
- antigo: 3 letras + 2 dígitos + 2 dígitos → `ABC-12-34`.
Outro → `INVALID_PLATE`. Método `masked()` → `ABC-***-MC` (esconde a parte numérica). JSON: string formatada.

**Ids** — `Ids.newId()` devolve UUID v7 (usar `com.github.f4b6a3:uuid-creator`, `UuidCreator.getTimeOrderedEpoch()`).

**BaseEntity** — `@MappedSuperclass` com `id UUID` (atribuído por `Ids.newId()` no construtor, não gerado pela BD), `createdAt`, `createdBy`, `updatedAt`, `updatedBy` (Spring Data auditing: `@CreatedDate`, `@CreatedBy`, `@LastModifiedDate`, `@LastModifiedBy`), `version long` com `@Version`. `equals`/`hashCode` por `id`. Activar `@EnableJpaAuditing` com `AuditorAware<String>` que devolve o `sub` do utilizador autenticado ou `"system"`.

**Migração** `V202610311200__shared_schemas_e_auditoria.sql`:
- `create schema if not exists` para: `audit, identity, organization, vehicle, catalog, rating, proposal, payment, policy, document, notification, verification, claim, complaint, assistance, reporting, fraud, integration`.
- Tabela:

```sql
create table audit.audit_event (
  id           uuid primary key,
  occurred_at  timestamptz not null,
  actor_id     varchar(64) not null,
  actor_type   varchar(20) not null check (actor_type in ('CUSTOMER','STAFF','SYSTEM','SERVICE')),
  insurer_id   uuid null,
  action       varchar(80) not null,
  entity_type  varchar(60) not null,
  entity_id    varchar(64) not null,
  before_state jsonb null,
  after_state  jsonb null,
  ip           varchar(45) null,
  trace_id     varchar(64) null
);
create index ix_audit_entity on audit.audit_event (entity_type, entity_id, occurred_at desc);
create index ix_audit_insurer on audit.audit_event (insurer_id, occurred_at desc);
```

- Configurar `spring.flyway.schemas` não é necessário; a migração cria os schemas. `spring.flyway.default-schema: public` mantém o histórico do Flyway em `public`.

**AuditService** — `record(AuditRecord r)` grava um evento; usado nas tarefas seguintes. Nesta tarefa só se cria e testa. O papel de BD só-de-inserção na tabela fica para o Sprint 11.
