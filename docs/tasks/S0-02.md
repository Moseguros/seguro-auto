## Especificação

**Maven:** `groupId mz.co.moseguros`, `artifactId backend`, `version 0.1.0-SNAPSHOT`, parent `spring-boot-starter-parent` 3.3.x (última patch), `java.version 17`. BOM `spring-modulith-bom` (versão compatível com Boot 3.3). Dependências: `spring-boot-starter-web`, `-validation`, `-actuator`, `-data-jpa`, `-security`, `-oauth2-resource-server`, `spring-modulith-starter-core`, `spring-modulith-starter-jpa`, `org.postgresql:postgresql`, `flyway-core`, `flyway-database-postgresql`, `springdoc-openapi-starter-webmvc-ui` (2.6.x), `mapstruct` + processor, `net.logstash.logback:logstash-logback-encoder`. Teste: `spring-boot-starter-test`, `spring-modulith-starter-test`, `spring-boot-testcontainers`, `org.testcontainers:postgresql`, `junit-jupiter`, `io.rest-assured:rest-assured`. Plugins: `maven-surefire` (unitários `*Test`), `maven-failsafe` (integração `*IT`), `jacoco` (relatório; o limite de 80% só se aplica a partir do Sprint 1).

**Configuração (`application.yml`):**
- `server.servlet.context-path` vazio; todos os controladores usam `/api/v1` no `@RequestMapping`.
- `spring.datasource.*` por variáveis: `DB_URL`, `DB_USERNAME`, `DB_PASSWORD`.
- `spring.jpa.open-in-view: false`, `hibernate.ddl-auto: validate`, `jdbc.time_zone: UTC`.
- `spring.flyway.schemas` vazio nesta tarefa (S0-03 cria os schemas).
- `management.endpoints.web.base-path: /api/v1`, expor só `health` e `info`; `management.endpoint.health.probes.enabled: true`.
- `spring.jackson.default-property-inclusion: non_null`, datas ISO.
- `local`: Postgres em `localhost:5432/moseguros`, utilizador `moseguros`/`moseguros`.
- `test`: datasource fornecido pelo Testcontainers (`@ServiceConnection`).

**Segurança (provisória até ao Sprint 1):** `SecurityFilterChain` que permite sem autenticação `/api/v1/health/**`, `/api/v1/meta/**`, `/v3/api-docs/**`, `/swagger-ui/**`, e nega tudo o resto (401). CSRF desligado (API stateless), sessão `STATELESS`.

**`GET /api/v1/meta/version`** → 200 `{"name":"moseguros-backend","version":"<project.version>","commit":"<git sha curto ou 'local'>","builtAt":"<ISO>"}` a partir de `BuildProperties`/`GitProperties` (plugins `spring-boot-maven-plugin` com `build-info` e `git-commit-id-maven-plugin` com `failOnNoGitDirectory=false`).

**Erros:** `GlobalExceptionHandler` (`@RestControllerAdvice`) devolve `ProblemDetail` (RFC 7807) com propriedades extra `code` e, para validação, `errors: [{field, code, message}]`. Casos: `MethodArgumentNotValidException` → 400 `VALIDATION_ERROR`; `ConstraintViolationException` → 400 `VALIDATION_ERROR`; `NoResourceFoundException` → 404 `NOT_FOUND`; `AccessDeniedException` → 403 `FORBIDDEN`; excepção de domínio `DomainException(code, status, detail)` → status e code dela; qualquer outra → 500 `INTERNAL_ERROR` sem detalhes internos (log com stack trace). Criar `mz.co.moseguros.shared.error.DomainException`.

**Logs:** perfil `local` em texto legível; restantes em JSON (logstash encoder) com `traceId` do MDC. Criar `MaskingPatternLayout`/conversor que mascara: números de telemóvel `258\d{9}` → `258*****1234` (últimos 4), sequências de 9 dígitos após `nuit` e cadeias `Bearer …`.
