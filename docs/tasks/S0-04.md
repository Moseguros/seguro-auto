## Objectivo

O contrato da API é gerado pelo backend para `api/openapi.yaml`, versionado no repositório, e há um comando que falha se o ficheiro estiver desactualizado. Web e mobile geram os seus clientes a partir deste ficheiro.

## Ficheiros

- `backend/src/main/java/mz/co/moseguros/shared/web/OpenApiConfig.java`
- `backend/pom.xml` (perfil Maven `openapi`)
- `api/openapi.yaml` (gerado)
- `scripts/check-openapi.sh`

## Especificação

- `OpenApiConfig`: título `MoSeguros API`, versão = versão do projecto, servidor `/`, esquema de segurança `bearerAuth` (HTTP bearer, JWT) declarado globalmente; endpoints públicos marcados com `@SecurityRequirements()` vazio.
- Ordenação estável do documento: `springdoc.writer-with-order-by-keys: true`, `springdoc.default-produces-media-type: application/json`.
- Componente `ProblemDetail` documentado com `code` e `errors`, e referido como resposta 4xx/5xx por defeito (`OpenApiCustomizer`).
- Value objects (`Money`, `Msisdn`, `Nuit`, `Matricula`) com esquema próprio (`@Schema` ou `ModelConverter`): `Money` objecto `{amount: int64, currency: enum [MZN]}`; os restantes `string` com `pattern` e `example`.
- Perfil Maven `openapi`: arranca a aplicação com o perfil Spring `test` + Testcontainers (ou com BD em memória desligada) e usa o `springdoc-openapi-maven-plugin` (1.4) para descarregar `/v3/api-docs.yaml` para `../api/openapi.yaml`. Alternativa aceite se o plugin for problemático: teste `OpenApiExportIT` que escreve o ficheiro quando `-Dopenapi.export=true`.
- `scripts/check-openapi.sh`: gera o ficheiro e corre `git diff --exit-code api/openapi.yaml`; sai com 1 e mensagem clara se houver diferenças.

## Critérios de aceitação

- [ ] `api/openapi.yaml` existe, é OpenAPI 3.0.x válido (validar com `npx @redocly/cli lint api/openapi.yaml` sem erros) e contém `/api/v1/meta/version`.
- [ ] Gerar duas vezes seguidas produz exactamente o mesmo ficheiro.
- [ ] `scripts/check-openapi.sh` passa no estado commitado e falha se o ficheiro for alterado à mão.
- [ ] Swagger UI disponível em `/swagger-ui.html` no perfil `local`, desligado em `prod` (`springdoc.swagger-ui.enabled: false`).

## Comandos de verificação

```bash
./scripts/check-openapi.sh
npx --yes @redocly/cli lint api/openapi.yaml
```
