## Objectivo

`web/` é uma aplicação React que arranca, mostra a versão da API, tem as rotas de todas as áreas (vazias), o layout com menu por área, i18n em pt-MZ e o cliente da API gerado do `api/openapi.yaml`.

## Ficheiros principais

- `web/package.json`, `pnpm-lock.yaml`, `vite.config.ts`, `tsconfig.json`, `.eslintrc.cjs` (ou `eslint.config.js`), `.prettierrc`, `orval.config.ts`, `index.html`
- `web/src/main.tsx`, `App.tsx`, `router.tsx`
- `web/src/theme/theme.ts`
- `web/src/i18n/index.ts`, `web/src/i18n/locales/pt-MZ.json`, `en.json`
- `web/src/layout/AppLayout.tsx`, `PublicLayout.tsx`
- `web/src/pages/HomePage.tsx`, `NotFoundPage.tsx`, uma página vazia por área
- `web/src/api/` (gerado pelo orval — não editar à mão)
- Testes: `web/src/**/*.test.tsx`, `web/e2e/smoke.spec.ts`

## Especificação

- Node 20 LTS, pnpm 9; Vite 5 + React 18 + TypeScript 5 com `strict: true`, `noUncheckedIndexedAccess: true`.
- Dependências: `react-router-dom` 6, `@tanstack/react-query` 5, `@mui/material` 6 + `@emotion/*`, `@mui/icons-material`, `react-hook-form`, `zod`, `@hookform/resolvers`, `i18next`, `react-i18next`, `axios`. Dev: `orval`, `vitest`, `@testing-library/react`, `@testing-library/jest-dom`, `jsdom`, `@playwright/test`, `eslint` + `typescript-eslint` + `eslint-plugin-react-hooks`, `prettier`.
- **orval**: entrada `../api/openapi.yaml`, saída `src/api/generated.ts`, cliente `react-query`, mutator Axios em `src/api/http.ts` com `baseURL = import.meta.env.VITE_API_BASE_URL ?? '/api'` (o prefixo `/api/v1` vem do contrato). Script `pnpm api:generate`.
- **Proxy Vite** em desenvolvimento: `/api` → `http://localhost:8080`.
- **Tema MUI** a partir de `docs/brand/README.md`: `primary.main #142D4E` (azul profundo), `secondary.main #F28C28` (laranja, com `contrastText #142D4E`), `background.default #E8EFF6`, `background.paper #FFFFFF`; fonte `Inter` (Google Fonts) com fallback do sistema; `shape.borderRadius: 8`. Modo escuro pela preferência do sistema com as variantes do mesmo ficheiro. Criar a variante de botão `variant="cta"` (fundo laranja) reservada às acções de conversão: Simular seguro, Comparar propostas, Adquirir apólice, Renovar seguro.
- **Logótipo**: copiar `docs/brand/logo.svg` e `docs/brand/logo-mark.svg` para `web/public/brand/`; favicon gerado a partir do `logo-mark.svg`. O logótipo é provisório e será substituído só nesses ficheiros.
- **Rotas** (todas com página "Em construção" traduzida, excepto `/`): `/cliente/*`, `/admin/*`, `/seguradora/*`, `/mediador/*`, `/perito/*`, `/oficina/*`, `/assistencia/*`, `/provedor/*`, `/supervisao/*`, `/frota/*`, `/verificar`, `/v/:token`, `*` → 404.
- **Layout**: `AppLayout` com barra superior (logótipo e nome "MoSeguros", selector de língua pt/en) e menu lateral cujos itens dependem da área da rota; em ecrãs < 900 px o menu passa a gaveta. `PublicLayout` sem menu para `/`, `/verificar`, `/v/:token`.
- **Menus** em `src/layout/menus.ts`: `export const menus: Record<Area, MenuItem[]>` com `type MenuItem = { key: string; path: string; icon: SvgIconComponent }`. O texto de cada item vem da chave i18n `menu.<área>.<key>`.
